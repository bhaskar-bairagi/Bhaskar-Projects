# Portfolio Overview

This repository is a collection of personal AI/ML projects, organized by vendor/platform, 
built to explore and demonstrate practical experience with different AI APIs and tooling.

## Structure

- **claude-projects/** — Projects built with the Anthropic Claude API
- **openai-projects/** — Projects built with the OpenAI API (planned)

## Purpose

Hands-on exploration of LLM APIs, prompt engineering, and building real applications 
(command-line tools, web UIs) around them — complementing professional architecture 
and engineering work with direct implementation experience.
