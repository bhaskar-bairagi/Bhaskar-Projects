# GCP learning projects

These projects teach GCP architecture decisions through locally runnable examples. No cloud account is needed to run them.

| Project | Demonstrates | Run locally |
|---|---|---|
| [Finance reconciliation lab](finance-reconciliation/) | Data validation, matching, exception review and a GCP pipeline mapping | Streamlit + Python |
| [Azure to GCP migration decision lab](azure-to-gcp-migration-lab/) | Inventory, migration waves, VM versus container route, validation and rollback | Streamlit + Python |

Cloud diagrams and mappings describe possible deployments. The code in each project is the implemented evidence; cloud resources are not provisioned.
