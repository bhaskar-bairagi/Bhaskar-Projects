# Bhaskar's Personal Projects

A personal portfolio of AI/ML projects, organized by platform.

## Structure

| Folder | Description |
|---|---|
| [`claude-projects/`](./claude-projects) | Projects built with the Anthropic Claude API |
| [`openai-projects/`](./openai-projects) | Projects built with the OpenAI API (planned) |
| [`docs/`](./docs) | Portfolio documentation |

## Featured Projects

- **[Simple Chatbot](./claude-projects/Simple_Chatbot)** — Command-line multi-turn chatbot using the Claude API
- **[Streamlit Chatbot](./claude-projects/Streamlit_Chatbot)** — Web UI chatbot with streaming responses, citations, file upload, and web search

## Setup

Each project folder contains its own README with setup instructions. A shared `.env` 
file at the repository root holds API keys used across projects.
